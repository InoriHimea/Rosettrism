# 2026-06-06 — v1.8.0 測試基線補強

## 背景

- v1.8.0 完成 README 開源格式與 AGPLv3 授權同步後，需要補上可重複執行的測試基線。
- Server API 已包含 `/api/health`、`/api/stats`、`/api/runs`、`/api/cache/:id` 與 Server Token 驗證，需用 Axum router integration tests 固定行為。
- Dashboard 目前已有 Vite build，但缺少明確的 `npm test` / smoke 腳本作為前端最小驗收。

## 目標

- [x] 新增 Axum router 層級測試，覆蓋 `/api/health`、`/api/stats`、`/api/runs`、`/api/cache/:id`。
- [x] 固定 Server Token 行為：未帶 token 回 `401` JSON，`x-rosettrism-token` 與 `Authorization: Bearer` 正確時通過。
- [x] 為 `cache_detail` handler 補上 upstream、unified、missing id 三種情境。
- [x] 在測試紀錄固定 localhost proxy bypass：`NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost cargo test`。
- [x] 為 frontend 新增 Playwright smoke test 腳本，驗證 Dashboard 載入、Settings token input 可操作、Fetch 頁可渲染。
- [x] 更新 `requirement.md` 的 v1.8.0 測試基線目標與驗收結果。

## 非目標

- 本次不更動 API response schema，僅補測試覆蓋。
- 本次不導入 ESLint 或更大型的前端測試框架遷移。
- 本次不新增 provider network mock 或端到端真實 provider 測試。

## 風險

- Playwright browser runtime 可能在部分環境缺少瀏覽器安裝；以 smoke script 固定入口，若環境不足需在測試紀錄註明。
- Router 測試若依賴外部網路會不穩定；本次使用 SQLite temp cache 與 Axum `oneshot`，避免實際開 port 或 provider 呼叫。
- proxy 環境變數可能干擾 localhost；測試紀錄明確固定 `NO_PROXY` / `no_proxy`。
